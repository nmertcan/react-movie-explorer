# React Movie Explorer

Film listeleme, kategori filtreleme, arama, detay sayfası ve favori ekleme özellikleri olan React uygulaması.

## Kurulum

```bash
npm install
```

## Çalıştırma

```bash
npm run dev
```

Tarayıcıda Vite'ın verdiği adresi aç.

## Özellikler

- SampleAPIs Movie API üzerinden kategoriye göre film listeleme
- Film adına göre arama
- Film detay sayfası
- Detaydan veya karttan favori için film seçme
- Açıklama validasyonu ile favorilere ekleme
- Favoriler sayfasında listeleme ve silme
- Responsive tasarım
